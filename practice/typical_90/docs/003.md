# 003
問題: https://atcoder.jp/contests/typical90/tasks/typical90_c

## 方針
> どの都市の間も、いくつかの道路を通って移動可能なものとなっています。

> N≤100000より、O(n^2)はNG

初期状態の木に対して、適切な一本を引いて最も多くのノードを通る閉路を作成する問題

幅優先して、一番深い二つの葉をつなげばいいのでは？

## 実装のメモ

みたいな場合のスコアの出し方がめんどくさそう

'''
a - b - c - d
        |   |
        e - f
'''

同じ深さの場合は一番深い段階と浅い段階で分岐しているほうの葉を選びたい

'''
a - b - c - e
|   |   |
|   |   - f
|   |
|   - i - j
|
- g - h - l # これ
'''

木のなかで一番長い場所を見つければよいのでは

深さ優先して、一番深い葉を見つけた後、そこからもう一度深さ優先して、一番深い葉を見つけると、最も長い場所を見つけることができる
