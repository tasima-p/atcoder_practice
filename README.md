# AtCoder Practice Repository

これは、AtCoderの問題を解くためのリポジトリです。

## ディレクトリ構造

コンテストの種類と開催回ごとにディレクトリを分けて、解答コードを管理します。

```
practice/
└── abc/
    ├── abc001/
    │   ├── a.cpp
    │   └── b.cpp
    └── abc002/
        ├── a.cpp
        └── b.cpp
```

## 使用言語

- C++
- Python
